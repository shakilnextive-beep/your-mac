# Your Mac

A Windows-style file explorer for macOS — **This PC**, tabs, Liquid Glass themes, dual pane, columns, tags and more.

## ⬇️ Download

**[Download the latest version](https://github.com/shakilnextive-beep/your-mac/releases/latest)** — open the `.dmg` and drag **Your Mac** into **Applications**.

Works on macOS 14 (Sonoma) or later, on both Apple Silicon and Intel Macs. Once installed, Your Mac updates itself.

## First launch

Your Mac isn't signed with an Apple developer certificate, so macOS asks once:

1. Click **Done** on the warning.
2. Open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**.

Or run this in Terminal:

```bash
xattr -dr com.apple.quarantine "/Applications/Your Mac.app"
```
